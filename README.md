## Installation

```bash
pip install git+https://github.com/jackai-dev/boxfleet-sdk-python.git
```

## Quick Start

```python
from boxfleet_sdk import Client

client = Client(
    base_url="https://boxfleet.io",
    api_key="bf_live_...",
)

catalog = client.cloud.get_white_label_cloud_catalog()
box = client.cloud.create_cloud_box(
    template_id="boxfleet-gpu-h100",
    backend="beam",
)
```

## Covered BoxFleet (`boxfleet` / `boxfleek`) API Namespaces

| Namespace | Operations | Description |
| :--- | :--- | :--- |
| `system` | `getHealth`, `getCapabilities`, `listProviders`, `listMods` | Inspect 66+ providers, 9 AI coding client mods, and runtime limits |
| `jobs` | `inspectProject`, `startProjectJob`, `startAgentJob`, `startGithubJob`, `listJobs`, `getJob`, `getJobLogs`, `getJobExecution`, `cancelJob` | Execute builds, tests, autonomous host-relay agents, and GitHub workflows |
| `cloud` | `getWhiteLabelCloudCatalog`, `listCloudBoxes`, `createCloudBox`, `performCloudBoxAction`, `syncCloudBoxVault` | Provision zero-idle-cost (`$0/hr` idle) White-Label Cloud VMs, X11 desktops (`:1`), H100 GPUs, and `/run/boxfleet/vault` `tmpfs` secrets |
| `fleet` | `listSaasPlans`, `getOrganizationFleet`, `updateOrganizationFleetPolicy`, `listOrganizationMembers`, `upsertOrganizationMember`, `registerWaitlistInvite`, `listWaitlistInvites` | JackAISaaS Connect entitlements, Business/Enterprise fleet governance, and Invite-Only Beta waitlist ledger |
